    <p>Simply add a new entry to <code>story.json</code>:</p>
    <pre style="background: #1e293b; color: #e2e8f0; padding: 1rem; border-radius: 18px; overflow-x: auto;">
"your_scene_id": {
  "text": "The description of the scene.",
  "image": "URL_TO_IMAGE",
  "choices": [
    { "text": "Choice A", "next": "another_scene_id" }
  ]
}</pre>
    <p class="text-muted"><i class="bi bi-git"></i> Link scenes using unique IDs and watch your story grow.</p>
